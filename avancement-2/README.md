## Message important

Cs-Stonks ne doit pas etre presente comme un clone de CSFloat.

Le positionnement est plutot :

- une plateforme de consultation et d'analyse type CSGOSkins / CS2Skins ;
- enrichie avec un vrai portfolio utilisateur ;
- connectee a l'inventaire Steam ;
- capable de regrouper plusieurs marketplaces ;
- avec une page d'analyse graphique avancee incluant zoom, annotation et stylo ;
- orientee suivi personnel, decision et visualisation de marche.

Le coeur du projet n'est donc pas seulement le prix d'un item.
Le coeur du projet est de donner a l'utilisateur un espace personnel pour
comprendre, suivre et analyser son activite CS2.
